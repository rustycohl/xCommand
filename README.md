# xCommand

Deterministic tactical authority with a strict Base-10 action economy.

This is an independent Ground Zero Gaming server-card port:

- repository: `rustycohl/xCommand`
- Page: https://rustycohl.github.io/xCommand/
- flag: `DEDICATED_REPO_PAGE`
- status: `alpha`
- dependencies: `d10SRD`

This extracted alpha proves AP authority, not the full Godot tactical engine.

## Verify


runtime dependency and does not introduce game-server authority.
